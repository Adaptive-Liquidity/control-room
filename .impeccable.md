## Design Context

### Users
Marketing operators at Adaptive Liquidity / AEON Protocol — editors, managers, and admins who live in this tool daily to create, review, schedule, and attribute content. Context is focused work sessions, not browsing. Primary jobs: clear the approval queue, draft compliant content, monitor agent status, and understand what content drives signups/integrations.

### Brand Personality
Precise · Operational · Dense

Emotional goals: control-room confidence. The UI should feel like a terminal built for people who live in it all day — high information density, muted chrome, functional color only.

### Aesthetic Direction
- **Theme:** Dark "command center" / terminal — near-black backgrounds (`#090909` bg, `#0f0f0f` panels, `#1e1e1e` hairline borders)
- **Source of truth:** ported 1:1 from `Agent Command Center` Figma Make prototype (`c:\Users\Benna\Documents\AEON-MARKETING\Agent Command Center`)
- **References:** Bloomberg Terminal, Paperclip agent views — small tabular fonts, maximum information density
- **Anti-references:** Neon/cyberpunk palettes, blue/teal/purple decorative accents, gradients, emoji navigation, oversized `font-black` metric cards, glassmorphism, "All Systems Operational" status theater
- **Typography:** Inter (UI/body) + JetBrains Mono (numbers, timestamps, IDs, small uppercase tracked labels/badges)
- **Accent:** No decorative accent color. Functional-only: green (`success`) = online/pass, amber (`warning`) = pending/caution, red (`destructive`) = error/fail. Primary CTA is an inverted light-gray-on-dark pill, not a color accent.
- **Motion:** Minimal — a single green "live" pulse-glow on active/online status dots only; quiet 0.18s fade-in on page mount. No other decorative animation.

### Design Principles
1. **Data density** — small tabular fonts, tight padding, no oversized hero chrome
2. **Functional color only** — green/amber/red mean something specific (status); everything else is grayscale
3. **No AI cosmetics** — no neon, no gradients, no emoji icons, no fake telemetry badges
4. **Quiet navigation** — ghost-style text links (muted → foreground on hover), no underlines, no colored nav pills
5. **One primary action** — clear CTA per view; secondary actions stay visually quiet (outline/ghost)
